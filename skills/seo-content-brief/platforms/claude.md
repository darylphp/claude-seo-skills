# Claude

Documentation checked 6 November 2026.

## Claude app

Stage the runtime files in the `seo-content-brief/` folder. ZIP the folder so the archive contains `seo-content-brief/SKILL.md` and `seo-content-brief/references/`. In Claude, open **Customize**, then **Skills**, then **Create skill** and **Upload a skill**. Availability depends on account capability and organisation settings.

[Anthropic Help Center: Create custom skills](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) · [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## Claude Code

Copy the runtime folder to `.claude/skills/seo-content-brief/` for the project or `~/.claude/skills/seo-content-brief/` for the local user. Keep `SKILL.md` and `references/` together. Use `/seo-content-brief` to invoke it explicitly with the source pack.

[Anthropic documentation: Extend Claude with skills](https://code.claude.com/docs/en/skills)
