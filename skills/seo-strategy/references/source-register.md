## Differences from the playbook

- S06: the playbook paraphrases the local factors as "relevance, distance and popularity". This skill uses "prominence", the factor name in Google's heading, and notes the introduction's wording.
- S14: the playbook lists data anomalies among the causes of a drop. The page checked on 20 Nov 2026 lists algorithmic updates, position drops, technical, security and spam issues, seasonality and changing interests, and site moves. The skill paraphrases that list.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
