# ChatGPT

For v0.1.0, installation has not been tested, invocation has not been confirmed and no behaviour case has been run on ChatGPT. Results from Claude would not show how ChatGPT behaves.

The same `SKILL.md` and `references/` files are intended for ChatGPT. Keep this folder as the single source and build any ChatGPT package from the same reviewed revision, so each rule is edited in one place.

## Upload

OpenAI's help page describes uploading a skill from **Skills**, then **Create**, then **Upload from your computer**. That path and its plan list (ChatGPT Business, Enterprise, Healthcare and Edu) were checked on 20 November 2026 for the SEO Strategy Skill. The page could not be opened on 27 November 2026, so treat both as carried forward. Availability in a particular workspace depends on its plan and administrator settings.

**[needs platform verification]** The help page does not state the accepted archive layout, any frontmatter or description limits, or whether Free, Plus and Pro users can upload skills. A test upload of the same ZIP used for Claude, with `site-architecture/` at the archive root, would settle the layout and whether one package works on both platforms.
