## Differences from the playbook

- **G7:** the playbook records that Google's AI guide does not require a new URL for every related query. The current page goes further: creating separate content for every search variation or fan-out query primarily to manipulate rankings or AI responses violates Google's spam policies, and a high quantity of pages does not make a site higher quality. The skill uses the current wording.
- **G9:** the playbook summarises this page as navigation and product discovery through crawlable links. The current page also says Google generally does not look at URL structure to work out a site's structure and analyses the links between pages instead. The skill adds this to its rule against changing stable URLs for tidiness.
- **G13 and G14:** not in the playbook's register. Added for URL naming, the advice not to reorganise a site only for search, and the limited ranking effect of keywords in the URL path.
- **G15 to G18:** not in the playbook's register. Added for redirect retention and references, hreflang, sitemap hints and pagination. The playbook routes these to File 09, and the skill keeps their implementation with the technical work.
- **G19:** no entry between 1 October and 24 November 2026 changed the redirect, canonical, link, faceted navigation, sitemap or localized-version guidance. The 23 November entry added a back-button hijacking FAQ to the spam policies, which this skill does not use.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
