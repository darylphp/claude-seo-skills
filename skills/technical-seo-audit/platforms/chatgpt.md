# ChatGPT

Documentation checked 27 November 2026 for the upload path. For v0.1.0, installation has not been tested, invocation has not been confirmed and no behaviour case has been run on ChatGPT. Results from Claude would not show how ChatGPT behaves.

The same `SKILL.md` and `references/` files are intended for ChatGPT. Keep this folder as the single source and build any ChatGPT package from the same reviewed revision, so each rule is edited in one place.

## Upload

OpenAI's help page describes uploading a skill from **Skills**, then **Create**, then **Upload from your computer**. Its plan list was checked on 20 November 2026 for the SEO Strategy Skill (ChatGPT Business, Enterprise, Healthcare and Edu) and could not be reopened on 27 November, so treat it as carried forward. Availability in a particular workspace depends on its plan and administrator settings.
